#  Windows Server Hardening

Repositório criado para documentar o processo completo de hardening aplicado em Windows Server, incluindo políticas de senha, firewall, serviços, auditoria e evidências.

##  Arquivos do Projeto

- **hardening_windows.md**  
  Guia completo contendo:
  - criação e configuração inicial do servidor  
  - políticas de senha  
  - regras de firewall  
  - serviços desnecessários desativados  
  - auditoria de segurança  
  - testes de validação  
  - evidências  


---

##  Objetivo

Fornecer um material organizado, direto e profissional para estudos, portfólio e demonstração prática de conhecimentos em hardening de Windows Server, seguindo boas práticas recomendadas pelo CIS Benchmarks e Microsoft Security Baselines.
